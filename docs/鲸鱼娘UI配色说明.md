# 鲸鱼娘 UI 配色方案

> 基于 DeepSeek 社区鲸鱼娘（大肥鱼）的视觉设定优化

## 配色理念

**核心主题**：海洋蓝 + 粉色腮红点缀  
**设计参考**：DeepSeek 蓝色鲸鱼 logo，社区鲸鱼娘拟人化形象（蓝发、鲸鱼鳍、傲娇性格）

## 主色板

| 用途 | 变量名 | 颜色值 | 说明 |
|---|---|---|---|
| **主文字** | `--ui-ink` | `#0d3a5f` | 深海蓝，代表鲸鱼的深海栖息地 |
| **次要文字** | `--ui-muted` | `#4a7ba7` | 柔和海蓝，降低视觉重量 |
| **强调色** | `--ui-accent` | `#1e88e5` | 鲸鱼主色调，Material Design Blue 600 |
| **背景** | `--ui-soft` | `#e3f2fd` | 浅天空蓝，呼应水面和天空 |
| **边框** | `--ui-line` | `#b3d9f2` | 水蓝色边框，柔和不刺眼 |
| **聚焦** | `--ui-focus` | `#0d47a1` | 深蓝聚焦态 |
| **腮红粉** | `--ui-blush` | `#ff9cc2` | 鲸鱼娘标志性腮红，用于点缀 |

## 交互状态

### Hover 悬停
- 按钮文字：`#0d3a5f`（深海蓝）
- 边框：`#64b5f6`（亮蓝，Light Blue 300）

### Selection 选中
- 背景：`#b3e5fc`（浅天空蓝）
- 文字：`#01579b`（深蓝，Light Blue 900）

### Scrollbar 滚动条
- 滑块：`#64b5f6`（亮蓝）
- 轨道：透明

|---|---|---|

| 强调色 | `#365f86` 沉稳蓝 | `#1e88e5` 鲜明蓝 |
| 背景 | `#f1f5f9` 冷灰 | `#e3f2fd` 浅天空蓝 |

| 腮红 | `#f08fa8` 浅粉 | `#ff9cc2` 鲜粉 |

## 设计特色

1. **海洋渐变**：头像采用 `#64b5f6 → #1e88e5` 渐变，模拟海水深浅变化
2. **腮红点缀**：`#ff9cc2` 仅用于当前标签下划线等关键提示，不泛滥使用
3. **柔和过渡**：边框和背景色明度接近，减少视觉跳跃
4. **高对比度**：主文字 `#0d3a5f` 在白底上对比度 7.8:1，符合 WCAG AAA
