# 桌宠 v1.1.1 设置简化方案

## 背景

v1.1.0 的"导演 / API"设置页包含大量高级配置，普通用户难以理解。本次简化将日常功能保留在桌宠，将服务管理和高级配置迁移到启动器。

## 分工原则

- **桌宠**：开箱即用的日常功能，普通用户自助完成
- **启动器**：服务部署、高级配置、系统维护，需要一定技术背景

## 具体划分

### 一、桌宠保留（简化后）

#### 1. 快速设置（保持原样）
- ✅ 能聊天：API 地址 + 模型 + 密钥，保存并连接
- ✅ 能听：启动 ASR 按钮（跳转启动器）
- ✅ 能说：系统语音 / GPT-SoVITS 切换，保存并试听

#### 2. 外观（保持原样）
- 对话字号、气泡距离
- 人物背景（透明/纯色/图片）
- 对话框背景

#### 3. 动作（保持原样）
- 视线跟随、呼吸、生动程度
- 键盘响应、摄像头感应
- 表演试演（22 手势 + 12 情绪）

#### 4. 角色（保持原样）
- 导入 Live2D 模型
- 角色切换

#### 5. 窗口（保持原样）
- 尺寸、位置、置顶、透明度

#### 6. 导演 / API（大幅简化）
**保留**：
- 连接模型（地址 + 模型 + 密钥）
- 导演试演（本地/远程）
- 启用直接接入开关
- 允许向服务商发送对话

**删除/移走**：
- ❌ 统一人设 → 移到启动器"高级配置"
- ❌ 显式记忆库 → 移到启动器"记忆管理"
- ❌ 自主陪伴 → 移到启动器"自主陪伴"
- ❌ 本次感知 → 移到启动器"调试工具"
- ❌ 限时共享 → 移到启动器"高级配置"
- ❌ 旧数据清理 → 移到启动器"系统维护"
- ❌ 控制 API 诊断 → 移到启动器"调试工具"
- ❌ 上下文预算、分词器 → 移到启动器"高级配置"
- ❌ TTS 设置（手动填路径） → 移到启动器"服务配置"

#### 2. 高级配置（新标签页）
将桌宠"导演 / API"的复杂部分移到这里：

**统一人设**：
- 长文本编辑器（支持语法高亮）
- 导入/导出 JSON
- 字段说明悬浮提示

**上下文预算**：
- 分词器选择（通用保守 / DeepSeek V4）
- 总预算、输出预留、封装余量

**限时共享**：
- 字段选择预览
- 共享/撤回

**控制 API**：
- 端口配置
- 允许诊断 eval 开关

#### 3. 记忆管理（新标签页）
完整的显式记忆库界面，从桌宠搬过来：

- 事件录入与编辑
- 摘要压缩
- 表达建议
- 来源谱系与级联删除
- 授权与撤权

#### 4. 自主陪伴（新标签页）
从桌宠搬过来的完整配置：

- 运行方式（离线规则 / API）
- 陪伴语气
- 频率控制（检查间隔、上限）
- 感知权限（窗口标题、截图）
- 虚拟作息与节奏

**新增**：
- 自主日志回放
- API 调用历史
- 费用统计（如果接入计费 API）

#### 5. 系统维护（新标签页）
- 旧数据清理（从桌宠搬过来）
- 配置备份与恢复
- 日志归档与清理
- 诊断报告生成

## 用户体验优化

### 新手流程
1. 双击"启动器.cmd"
2. 点击"启动"标签 → "启动桌宠"
3. 桌宠弹出 → 进入"快速设置"
4. 填写 API 地址、模型、密钥 → 保存并连接
5. 完成，可以聊天

### 进阶流程（需要 TTS）
1. 桌宠"快速设置" → "一键启动 TTS"
2. 自动跳转启动器"服务"标签
3. 点击"启动 GPT-SoVITS"
4. 返回桌宠 → 保存语音配置

### 高级流程（自主陪伴）
1. 启动器 → "自主陪伴"标签
2. 配置运行方式、频率、感知权限
3. 点击"开始自主运行"
4. 启动器显示实时状态，可随时停止

## 技术实现

### 启动器与桌宠通信
- 桌宠主进程暴露 HTTP API（已有 127.0.0.1:端口）
- 启动器通过 API 查询状态、发送控制指令
- 启动器用 WebSocket 接收实时日志

### 服务管理
- 启动器用 PowerShell `Start-Process` 启动 ASR/TTS
- 用 `Get-Process` 监控进程状态
- 用 `Test-NetConnection` 检测端口

### 配置同步
- 桌宠和启动器共用 `%APPDATA%\DafeiyuDesktopPet\config.json`
- 启动器修改高级字段后，桌宠热重载
- 避免冲突：启动器锁定高级字段时，桌宠只读显示
