# 大肥鱼桌宠（Live2D Desktop Pet）

基于 **Electron + Live2D** 的桌面宠物，当前版本 **v1.1.0**。

她会说话、对口型，说话时跟着语气点头抬眉；聊天时由模型在台词里安排手势和情绪，像虚拟主播一样表演；也可以在你玩游戏、写代码时坐在旁边看屏幕点评。模型来自 DeepSeek 免费公皮（不随仓库分发）。

## 功能

### 表演
- **口型同步**：按语音音量驱动张嘴，主窗气泡语音和聊天窗语音都生效
- **生动层**：平时头、眉、眼球有细微的不自主晃动；说话时按重音点头、换侧微转、抬眉
- **表演层**：22 个多通道手势（点头、歪头、哼、蹦、坏笑、敷衍、心动、跺脚、凑近看……）和 12 种持续情绪（开心、喜欢、害羞、难过、生气、得意、无语……）
  - 手势带预备动作与回弹，眼和眉先动、头随后、身体最后，每次幅度和左右略有不同
  - 情绪带身体摆动和前倾后仰，并联动模型自带表情（无语 → 屑屑眼，喜欢 → 爱心眼 + 脸红，难过 → 流泪……）
- **台词行内标记**：`〔开心〕哇，这把〔蹦〕赢了！〔歪头:右〕真的假的`，标记不显示、不朗读，动作按语音进度落在对应的字上
- 视线跟随、点击反应（头 / 脸 / 腿 / 身体分区）、多表情叠加、vtube 热键、编舞引擎

### 对话（可选）
- 接入 OpenAI 兼容 API：设置 → 导演 / API → API，填服务地址、模型名、密钥，点「保存并连接」；连不上时会说明具体原因
- 人设、显式记忆、看屏幕
- **自主陪伴**：温柔关心 / 轻傲娇 / 安静克制 / **直播搭子**（定时看屏幕并点评，需授权窗口标题或截图）
- 密钥保存在 Windows DPAPI 加密文件中

### 语音合成（TTS，可选）
- 默认**关闭**，本仓库**不包含** GPT-SoVITS 服务与模型权重
- 设置 → 导演 / API → TTS 填写本地服务地址（如 `http://127.0.0.1:9880/tts`）

### 窗口
- **主窗**：只承载模型和说话气泡，支持像素级点击穿透
- **右键快捷菜单**：聊天 / 动作与表情 / 设置 / 看屏幕 / 收起
- **设置窗**：外观 / 动作 / 角色 / 窗口 / 导演·API；动作页可调「生动程度」「表演幅度」，并逐个试演手势和情绪
- **聊天窗**、**动作控制台**：独立窗口

## 运行

需要 Windows 和 Node.js。

```bash
npm install
```

```bash
npx electron .
```

启动时不要加 `--no-sandbox`，程序检测到会拒绝启动。

### 模型

`characters/` 目录**未随仓库分发**。请自行放入 Live2D 模型，按 `characters/<id>/manifest.json` 结构组织，或在 设置 → 角色 里导入 ZIP 模型包。

表演层的参数方向和表情联动是按 DeepSeek 免费公皮「大肥鱼」实测校准的；其它模型会退回 Cubism 标准参数名，没有对应表情时只做姿态。

## 测试

```bash
npm test
```

共 6 组、99 项：编舞引擎、口型、生动层、表演层、直播搭子、模型接入。全部不联网。

## 隐私

- 仓库**不包含**：API 密钥、桥接密钥、聊天记录、记忆库、DPAPI 加密文件、用户配置中的私密字段
- `config.json` 中 `llm` / `director` / `tts` 均默认关闭或留空，不会自动联网
- 点「保存并连接」表示同意把人设和你发的对话送到你填写的服务地址
- 直播搭子在 API 模式下会定时把已授权的窗口标题或截图发给该服务，可能产生费用
- 密钥只保存在本机 Windows DPAPI（当前用户作用域），同账户程序仍可能读取，请勿在共享电脑上保存敏感密钥

## 开发

- 主进程：`electron/`
- 渲染层：`renderer/`
  - `pet.js` 主逻辑，`live2d5.js` 渲染
  - `lip-sync.js` 口型，`liveliness.js` 生动层，`acting.js` 表演层
  - `director-*.js` 导演系统与台词标记
- 编舞引擎与测试：`engine/`
- 外部 Agent 接入：见 [docs/director-agent.md](docs/director-agent.md)，控制 API 在 `127.0.0.1:41968`（`/api/pet/*`）

## 已知限制

- 手臂不参与表演：模型的手臂是离散状态切换，连续驱动会出现贴图虚影
- 没有接入直播平台的弹幕来源
- 仅在 Windows 上验证过
