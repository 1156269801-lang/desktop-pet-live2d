# 大肥鱼桌宠（Live2D Desktop Pet）

基于 **Electron + Live2D** 的桌面宠物。模型来自 DeepSeek 免费公皮，支持导演系统（动作/表情/视线轨道）、聊天、多表情叠加、语音合成（可选，不随包分发）。

## 功能

### 窗口（拆窗方案）
- **主窗**：只承载模型 + 说话气泡
- **右键快捷菜单**：弹在鼠标位置，聊天 / 动作控制台 / 设置 / 看屏幕 / 收起；× / 再右键 / 点外部关闭
- **聊天窗**：独立窗口，带历史记录与打字机效果
- **设置窗**：外观 / 行为 / 绑定 / 导演·API（含 TTS）/ 关于
- **动作控制台**：动作、表情、参数调试

### 视觉与动作
- Live2D 模型（参数 / 动作 / 表情按模型能力表自动发现）
- 视线跟随（屏幕全局坐标）
- 多表情叠加（泪、脸红、眼镜等可同时开启）
- 导演标记：台词里写 `〔歪头:左〕`、`〔竖手指〕`、`〔清表情〕` 等即时生效
- vtube 热键（读取模型自带的 `.vtube.json`）
- 编舞引擎（planner → 轨道 → 采样）
- 点击反应（头/脸/腿/身体分区语料）
- 点击穿透（像素级不透明检测）

### 对话（可选）
- 聊天：接入 OpenAI 兼容 API（默认空配置，不联网）
- 人设 / 记忆 / 自主运行 / 看屏幕
- 密钥保存在 Windows DPAPI 加密文件中

### 语音合成（TTS，可选）
- 默认**关闭**，本仓库**不包含** GPT-SoVITS 服务与模型权重
- 可在 设置 → 导演/API → TTS 填写本地服务地址（如 `http://127.0.0.1:9880/tts`）
- 参考音频、说话语言均可配置

## 运行

```bash
# 1. 安装依赖
npm install

# 2. 启动
npx electron .
```

### 模型

`characters/` 目录**未随仓库分发**（请自行放入你的 Live2D 模型，按 `characters/<id>/manifest.json` 结构组织）。

## 隐私

- 仓库**不包含**：API 密钥、桥接密钥、聊天记录、记忆库、DPAPI 加密文件、用户配置中的私密字段
- `config.json` 中 `llm` / `director` / `tts` 均默认关闭或留空，不会自动联网
- 密钥只保存在本机 Windows DPAPI（当前用户作用域），同账户程序仍可能读取，请勿在共享电脑上保存敏感密钥
- TTS 服务与语音包不在本仓库，需要时请自行部署

## 开发

- 主进程：`electron/`
- 渲染层：`renderer/`（`pet.js` 主逻辑、`live2d5.js` 渲染、`director-*.js` 导演系统）
- 编舞引擎：`engine/`
- 控制 API：`127.0.0.1:41968`（`/api/pet/*`）
